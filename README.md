# Tableau Project | House Sales Dashboard
## Link to Tableau Dashboard:
https://public.tableau.com/app/profile/ruchi.asthana/viz/House_Sales_Dashboard_Ruchi_A/KingCountyHouseSales
## About the Project:
* In this project, we transform raw House Sales data into aesthetically appealing, interactive and easy-to-understand visualizations and charts.
* We then build a House Sales Dashboard which incorporates a Line Chart, a Map, 3 Histograms and a Heatmap.
  * Line Chart showing Daily Average House Sales Price.
  * Map showing Average House Sales Price by Zipcode.
  * Histogram showing the distribution of House Prices.
  * Histograms showing the distribution of Bedrooms and Bathrooms.
  * View (No View/Fair/Average/Good/Excellent) vs. Condition (Poor/Fair/Average/Good/Very good) Heatmap.
* The dashboard uses a Calendar widget as the main filter (users can select the month from the dropdown and select a specific date within the widget) along with other filters like 'Year Built', 'Sqft. Living', 'Sqft. Lot'.
## Some Insights:
* The Daily Average House Sales Price peaked on 24 May, 2015; crossing one million.
* Most houses have 3 bedrooms and 2 bathrooms.
* Most houses fall in the 200k to 400k price range.
* Houses in 'Very Good' condition and 'Excellent' views sell upwards of one million.
